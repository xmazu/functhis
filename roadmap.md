# Functhis Roadmap

- [ ] Ujednolicić wykonania: jeden `executionId`, wspólny format wyniku i poprawne błędy.
- [ ] Dodać logi użytkowników: Postgres na historię, Axiom na input/output/logi, Analytics Engine na statystyki.
- [ ] Dokończyć panel: lista wykonań, szczegóły, wersje, rollback i użycie limitów.
- [ ] Dokończyć developer experience: pełniejsze kontrakty, walidacja outputu, `functhis check` i `functhis dev`.
- [ ] Dodać bezpieczeństwo produkcyjne: redakcję sekretów, retencję, rate limiting, concurrency i kill switch.
- [ ] Dodać HTTP i strony funkcji obok istniejącego MCP.
- [ ] Dodać hosted secrets, OAuth connections, stan funkcji i pliki w R2.
- [ ] Później dodać harmonogramy, webhooki, eventy, workflow, katalog publiczny i uprawnienia zespołowe.
