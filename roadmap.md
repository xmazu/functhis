# Functhis Roadmap

- [x] Ujednolicić wykonania: jeden `executionId`, wspólny format wyniku i poprawne błędy.
- [x] Dodać logi użytkowników: Postgres na historię, Axiom na input/output/logi, Analytics Engine na statystyki.
- [x] Dokończyć panel: lista wykonań, szczegóły, wersje, rollback i użycie limitów.
- [ ] Dokończyć developer experience: pełniejsze kontrakty, walidacja outputu, `functhis check` i `functhis dev`.
- [x] Dodać bezpieczeństwo produkcyjne: redakcję sekretów, retencję, rate limiting, concurrency i kill switch.
- [x] Uzupełnić dokumentację i testy: wspólny `executionId`, limity payloadów, retencję planów, Axiom, cron cleanup i Stripe price env.
- [ ] Dodać HTTP i strony funkcji obok istniejącego MCP.
- [ ] Dodać hosted secrets, OAuth connections, stan funkcji i pliki w R2.
- [ ] Później dodać harmonogramy, webhooki, eventy, workflow, katalog publiczny i uprawnienia zespołowe.
